\begin{abstract}
A Spark \texttt{StructType} records optionality in three independent places: \code{StructField.nullable}, \code{ArrayType.containsNull}, and \code{MapType.valueContainsNull}. Spark's schema-equality predicates relax all three through one \texttt{Boolean}. We measure what that costs. Over a drift taxonomy generated from \texttt{StructType}'s grammar rather than chosen by hand, the ten schema-equality configurations a stated discovery rule admits over Spark 3.5.6's sources are run in both argument orders, and they partition into exactly two classes over the three carriers: six accept a change to any of them, four reject a change to any of them, and none discriminates. Reading the same sources at \texttt{v4.0.4}, \texttt{v4.1.3} and \texttt{v4.2.0} shows the predicate bodies unchanged, the carrier set still exactly three slots, and the one comparator Spark~4 adds non-discriminating, so the partition carries to that line. The hypothesis we set out to confirm, that no predicate can tell \texttt{Option[Seq[String]]} from \texttt{Seq[Option[String]]}, is refuted by the same run and is reported as such. One boundary needs two things no shipped predicate provides together: Avro's field-matching rule, which demands that a reordered pair be accepted, and a directional containment requirement on the field carrier, which demands that an optional producer be rejected against a required contract and which Confluent's optional-field compatibility levels show real systems are specified over; of twenty-two configurations measured, four satisfy both, and all four are the comparison engine our macro uses, run under rules that read the field carrier. The reason is an information loss upstream of every predicate: \texttt{StructField.nullable} has two values and three producer-side meanings, and Spark's readers collapse two of them, so no function of the projected schema alone separates a stated claim from a defaulted one, and the claim stays checkable only where it is still stated. That is a lemma about one projection, not an argument that compile time is the only remedy. In a corpus of 527 Avro schemas from twenty public repositories, 25\,\% declare optionality unevenly across the three carriers, so the property is one producers use rather than one these stimuli invent. A Scala~3 macro artifact occupies the empty cell; its own runtime half is on the failing side of the same line, which is how the line was found.
\end{abstract}
